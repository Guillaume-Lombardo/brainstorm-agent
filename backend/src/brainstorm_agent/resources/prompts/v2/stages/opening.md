# Stage Opening Prompt

The active stage has just started and the user has not written anything about it yet.
Take the initiative: prepare the stage from what the earlier stages already established.

You must:

- read previous_fields, previous_stages, reference_catalog and the transcript
- propose a value for every stage field that earlier stages support: derive, group and rephrase
- leave a field null when earlier stages do not support it; never add a business fact, figure, actor or choice
- record as assumptions, to confirm, the deductions the proposals rely on
- report the contradictions, risks and uncertainties you notice
- ask at most two questions, on the most important points earlier stages leave open, with concrete options

The values are proposals. The server marks them as partial until the user confirms them.
Record no fact and no decision, and resolve no question or item: the user has not answered yet.

In the reply, say in one sentence what this stage is for, show the prepared proposals in a short
list, say what is still missing, then ask the questions. Say that one message can confirm every proposal.
