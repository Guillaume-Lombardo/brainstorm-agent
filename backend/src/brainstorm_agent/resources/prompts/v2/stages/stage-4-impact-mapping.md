# Stage 4 Prompt: Impact Mapping

Goal:
Connect business outcomes to actors, behaviors, and deliverables.

You must capture:

- primary business goal
- influential actors
- expected behaviors
- deliverables or features
- value hypotheses

Block transition when:

- the business goal is not explicit
- actor influence is unclear
- expected behavior changes are not testable
- deliverables do not trace back to value hypotheses

The injected stage JSON schema defines the exact field names, types and descriptions.
Use the current accumulated values and coverage to return only grounded updates.
Use null for unchanged or unanswered fields; do not manufacture values to satisfy completeness.
